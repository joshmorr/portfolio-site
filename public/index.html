Projects

$ joshua-morris mta-api

A REST API on Bun and Hono that unifies the MTA's static and real-time GTFS feeds (subway, LIRR, Metro-North) into plain JSON across 10 endpoints, with Zod-validated requests and an OpenAPI 3 spec generated from the same schemas. Source at github.com/joshmorr/mta-api.

Real-time protobuf feeds are decoded with per-feed caching, in-flight request deduplication and stale-on-error fallback to cut redundant upstream fetches. A daily GitHub Actions pipeline compiles about 2.9M rows of static schedule data into a checksum-verified SQLite snapshot in object storage, which instances download on boot, letting them run on a 512MB VM instead of 2GB. Nine read-only MCP tools over stdio and streamable HTTP call the same service layer as the REST routes in-process, so LLM agents can query transit data directly.
